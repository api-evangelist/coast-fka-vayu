# Coast (FKA VayU)

> Coast (formerly VayU) is a US fintech that consolidates fuel cards, fleet and field cards, corporate cards, expense management, and bill pay onto one platform for fleet-based and field-service businesses. Coast exposes a v2 REST API and an embedded-widget SDK through a Kong-hosted developer portal (access gated behind OIDC login).

## APIs

- [Coast API v2](https://developers.coastpay.com/): v2 REST API for fuel/fleet cards, corporate cards, spend controls, transactions, and expense data. Base URL https://api.coastpay.com/v2.
